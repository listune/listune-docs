# Support

Need help with Listune? Here is how to get assistance, report issues, and contribute to the project.

## Join the Support Server

The fastest way to get help is to join the official Listune Discord support server. You can ask questions, report bugs, and chat with other users and the development team.

[Join the Support Server](https://listune.app/support)

## Common Issues

Before reaching out, check if your issue is covered here:

### The bot is not responding to commands

- Make sure Listune has the necessary permissions in the channel (Send Messages, Embed Links, Use External Emojis).
- Check that you are using slash commands (type `/` and look for Listune in the autocomplete list).
- If slash commands are not appearing, try kicking and re-inviting the bot. This re-registers the commands.

### The bot is not joining my voice channel

- You must be in a voice channel before using a playback command.
- Ensure Listune has the **Connect** and **Speak** permissions in your voice channel.
- If the bot is already in another voice channel in the same server, use `/forcejoin` to move it to yours.

### The music sounds distorted or cuts out

- Check your server's voice region. Sometimes switching to a different region can improve quality.
- If you have an audio filter active, try `/reset` to remove all filters and see if the issue persists.
- High latency to the audio node can sometimes cause audio issues. Check the [System Status](https://listune.app/status) page.

### A song is not playing from my link

- Ensure the URL is from a supported platform (YouTube, Spotify, SoundCloud, Apple Music, Deezer, Tidal).
- Some tracks may be region-locked or unavailable due to rights restrictions.
- Try searching for the song by name instead of using a direct link.

### Commands say I need a DJ role

- Your server administrator has configured a DJ role. Ask them to assign you the role, or have them disable it with `/djrole action:disable`.

## Reporting Bugs

If you encounter a bug, you can report it directly through the bot:

```
/report
```

This opens a form where you can describe the issue. Reports are sent to the development team for review.

## Feature Suggestions

Have an idea for a new feature? Submit it using:

```
/suggestions
```

The team reviews all suggestions and considers them for future updates.

## Supporting Listune

Listune is 100% free to use with no premium locked features. However, running a high-quality music bot requires servers, maintenance, and time. If you enjoy using Listune and want to help keep it running, there are a few ways you can support the project:

- **Donate** to help cover hosting and maintenance costs.
- **Vote** for Listune on Top.gg to help more servers discover the bot.
- **Share** Listune with other Discord server owners.

[Learn How to Support Listune](https://listune.app/how-to-support)
