# Invite and Setup

Getting Listune into your Discord server takes less than a minute. Follow the steps below to get started.

## Step 1: Invite the Bot

Click the link below to invite Listune to your server:

[Invite Listune](https://listune.app/invite)

You will be redirected to Discord's authorization page. Select the server you want to add Listune to from the dropdown menu, then click **Authorize**.

import { Callout } from 'nextra/components'

<Callout type="info">
You need the **Manage Server** permission in the target server to invite bots.
</Callout>

## Step 2: Verify Permissions

Once Listune joins your server, it needs a few permissions to function properly. Most of these are granted automatically during the invite process. Make sure Listune has the following:

| Permission | Why It Is Needed |
| --- | --- |
| Connect | Join voice channels to play music |
| Speak | Transmit audio in voice channels |
| Send Messages | Respond to commands and show now-playing info |
| Embed Links | Display rich embeds for song info and queues |
| Read Message History | Support interactive buttons and menus |
| Use External Emojis | Display custom status icons and source indicators |

If any command does not work as expected, double-check that Listune's role has these permissions in the channel where you are using it.

## Step 3: Join a Voice Channel

Before you can play music, you need to be in a voice channel. Listune will automatically join the same voice channel as you when you use a playback command.

## What Comes Next

You are all set. Head over to [Play Your First Song](/quickstart/first-song) to start listening.
